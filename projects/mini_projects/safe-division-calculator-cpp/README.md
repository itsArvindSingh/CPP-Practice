# Safe Division Calculator (C++)

## 📌 Description
This project is a simple C++ program that performs division safely using exception handling. It prevents runtime errors such as division by zero using try, throw, and catch.

---

## 🎯 Objective
To demonstrate the use of exception handling in C++ for handling runtime errors.

---

## ⚙️ Features
- Takes two numbers as input
- Performs division
- Handles division by zero using exception handling
- Displays appropriate error message

---

## 🧠 Concepts Used
- Classes and Objects
- Exception Handling (try, throw, catch)
- Basic Input/Output

---

## 💻 Code Structure
- Class: `SafeDivision`
- Functions:
  - `getData()` → Takes user input
  - `calculate()` → Performs division and handles errors
