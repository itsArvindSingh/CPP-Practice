# C++ Practice Programs Repository

## Overview

This repository contains a collection of basic to intermediate C++ programs created for learning and practice purposes. The programs focus on strengthening core programming concepts, problem-solving skills, and understanding of Object-Oriented Programming (OOP).

The collection covers mathematical operations, number-based logic, function techniques, and class-based implementations.

---

## Concepts Covered

### 1. Basic Programming

- Arithmetic operations  
- Input and output handling  
- Conditional statements  
- Loop-based calculations  

### 2. Number-Based Problems

- Reverse of a number  
- Palindrome checking  
- Prime number checking  
- Factorial calculation  
- Cube and square calculations  
- GCD of two numbers  

### 3. Functions

- User-defined functions  
- Inline functions  
- Function overloading  
- Mathematical calculations using functions  

### 4. Geometry & Measurement

- Area calculations for different shapes  
- Volume calculations for 3D objects  
- Temperature conversion between units  

### 5. Object-Oriented Programming (OOP)

- Class and object creation  
- Member functions inside class definition  
- Member functions outside class definition  
- Use of constructors and member variables  
- Programs for handling student information  
- Class-based calculator and number utilities  

---

## Purpose

The main objectives of this repository are:

- To build a strong foundation in C++  
- To understand procedural and object-oriented approaches  
- To practice real-world logic building  
- To prepare for academic labs, assignments, and interviews
